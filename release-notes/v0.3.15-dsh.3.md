Delegation proxy fix.

### Highlights

- The delegate child now inherits `HTTP_PROXY` / `HTTPS_PROXY` / `ALL_PROXY` /
  `NO_PROXY` (both cases) and `NODE_USE_ENV_PROXY` from the host environment.
- Fixes the 429 rescue path on proxied-only networks: `opencode serve` used to
  hang until the 120 s request timeout because it was spawned without the egress
  proxy; the delegated turn now completes in ~16 s.
- Verified with 452/452 tests and a headless free-model run through the delegate.
