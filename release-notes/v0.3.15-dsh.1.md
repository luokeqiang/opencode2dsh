First maintained-fork release.

### Highlights

- Adds tools relay: delegate tool calls are captured at the approval gate and executed by DSH, with results re-seeded into history.
- Adds `delegation.cwd` and host tool name/argument rewriting.
- Delegates on the first `429 FreeUsageLimitError` instead of waiting for a second failure.
- Falls back to session messages when `GET /permission` is broken, and scopes capture to the current session.
- Verified with 449/449 tests, headless `bash`/`grep`, and the web model catalog.
